# Saint Merdain

**Saint Merdain** — полностью вымышленный прибрежный мегаполис, представленный как кинематографический интерактивный атлас города. Проект исследует, как карта может передавать историю, атмосферу, инфраструктуру и повседневную жизнь.

**Сайт:** [saintmerdain.city](https://saintmerdain.city/) · [исходный код](https://github.com/jamilislamov642-cell/Saint-Merdain) · [лицензия](./LICENSE) · [развёртывание](./docs/deployment.md)

## Возможности

- Процедурный город на Three.js: побережье, рельеф, дороги, мосты, холмы, небоскрёбы и районы.
- Поиск, категории, фильтры районов, интерактивные места, карточки, избранное и режим день/ночь.
- Вращение камеры, наклон, масштабирование, фокус, основы маршрутов, кластеризация и анализ плотности.
- Статическая архитектура для GitHub Pages и собственного домена Cloudflare.

## Запуск локально

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
npm run preview
```

## Технологии и структура

React, TypeScript, Vite, Three.js, HTML и CSS. В `src/` находятся интерфейс, рендерер и данные; `public/` содержит метаданные; `standalone.html` — отдельная быстрая версия.
